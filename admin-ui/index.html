Supply accounting

Buffer

Initialize and activate token-scoped reserve and fee accounting.

Step 1

Initialize Buffer

Create

Create the token's USD pricer and active pricing vector first. Initialization derives the reserve, management-fee, and performance-fee vaults.

Step 2

Activate Buffer

Configure

This sets all three vault destinations first, then makes the Diamond the token's Buffer controller, then saves APR and fees. Once active, ordinary token mint and burn operations settle the Buffer automatically.
